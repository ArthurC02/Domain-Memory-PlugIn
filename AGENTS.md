# Domain Memory source repository

This repository builds the Domain Memory plugin. The plugin itself is the folder [`plugins/domain-memory/`](plugins/domain-memory/), and its guide for any agent using Domain Memory is [`plugins/domain-memory/AGENTS.md`](plugins/domain-memory/AGENTS.md).

To change the plugin, read [CONTRIBUTING.md](CONTRIBUTING.md): the engine source, its tests and recorded outputs live in `engine/`, and the executables it builds land in `plugins/domain-memory/engine/bin/`.
